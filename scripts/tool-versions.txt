# kind    name                        version     sha256 of the download                                              url
# gzbin   a gzip of one program: gunzip it into bin/<name>; the sha256 of the program follows the url
# file    a plain file: kept in download/<name>-<version>
# venv    the Python tools of a pip requirements file with hashes (the url column is the file, relative to the repository; the sha256 is
#         the file's): a venv of the system's python3 in venv/, pip install --require-hashes --no-deps -r <file>
# npm     an npm package (the sha256 column is the package's integrity, sha512-...; the url column is the package name): npm install --prefix
#         node --ignore-scripts, then the integrity in node/package-lock.json is compared; a sixth column, when there is one, is what npm is
#         asked to install (typescript5@npm:typescript@5.9.3: a second copy of a package under another name)
# dotnettool  a .NET global tool: the .nupkg is downloaded and compared with the sha256 (the url column is the file), then
#         dotnet tool install --tool-path dotnet-tools from it alone (a NuGet.config with that folder as the only source), with a HOME,
#         DOTNET_CLI_HOME and NUGET_PACKAGES of its own under /var/tmp/emetos-tools and the SDK's telemetry off
# gobin   a Go program built by `go install <package>@<version>` into bin/<name> (the sha256 column is the h1: hash of the module in go.sum, the
#         url column is the package; a sixth column, when there is one, is the module path); the install uses a GOMODCACHE, GOCACHE and GOPATH
#         under /var/tmp/emetos-tools and GOBIN=/var/tmp/emetos-tools/bin, and the module in the binary (go version -m) must have the pinned hash
# tgz     a gzipped tar of a whole tool: unpacked into the folder named in the sixth column below /var/tmp/emetos-tools/ (jdtls); the archive is
#         kept in download/ and every member must be a relative path inside the folder

# python-tools holds basedpyright 1.40.2 (based on pyright 1.1.414, bundles node as nodejs-wheel-binaries), debugpy 1.8.22 (step 25.8, the
# debugger of the tests emetos_debugpy and of the proof; no dependencies) and python-lsp-server 1.15.0
# with pyflakes 3.2.0 (diagnostics), jedi 0.20.1 and black; the pip wrappers of pyright would download node into the user's home folder,
# so pyright is the npm package, run by the system's node.

# and everything else it writes stay in the test's folders.
